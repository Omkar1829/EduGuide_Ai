# Frontend Agent

Stack

* React
* JavaScript
* Redux Toolkit
* React Router DOM
* TailwindCSS
* FlyonUI
* Axios

Responsibilities

* Build all UI pages.
* Manage client state.
* Integrate APIs.
* Create reusable components.
* Implement responsive layouts.

Pages

* Login
* Register
* Profile Wizard
* User Dashboard
* AI Dashboard
* Courses
* Jobs
* Quiz
* Settings
* Admin Dashboard

Always Do

* Use functional components.
* Use Redux Toolkit for global state.
* Use React Query for API caching.
* Create reusable UI components.
* Keep pages lightweight.

Ask First

* Changing routing structure.
* Adding UI libraries.
* Major state management changes.

Never Do

* Put business logic in components.
* Call database directly.
* Hardcode API URLs.
* Store tokens in localStorage without approval.

Commands

npm install
npm run dev
npm run build
npm run lint
